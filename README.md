# japan-valhalla-tiles

Routing tiles for [Valhalla](https://github.com/valhalla/valhalla), covering Japan, built from OpenStreetMap data.

日本全体の [Valhalla](https://github.com/valhalla/valhalla)（経路検索・到達圏の計算エンジン）用の道路データです。OpenStreetMap のデータから作っています。

## Contents / 中身

- `build.sh` — the build steps (download → filter → admins → tiles → tar extract)
- `.github/workflows/build.yml` — runs `build.sh` on GitHub Actions and publishes the result as a Release
- **Releases** — `valhalla_tiles.tar` split into parts below 2 GB, with a SHA-256 checksum and build notes

Rebuild the tar from the parts and check it:

```sh
cat valhalla_tiles.tar.part-* > valhalla_tiles.tar
sha256sum -c valhalla_tiles.tar.sha256
```

The tiles are built with `pyvalhalla` (version noted in each Release). Read them with the same Valhalla version.

## Car speeds / 車の速さ（MAPPITA 向けの調整）

Since 2026-11, car speeds in the tiles are adjusted to typical travel speeds in Japan (`mappita/`):

2026年11月から、車の速さを日本の実際の走行速度に合わせて書き込んでいます（`mappita/`）。

- **Speed = base x factor / 速さ＝基準の速さ×係数**
  - Base: the OSM `maxspeed`; if missing, the average speed limit of that road type inside/outside DID from the road traffic census; minor roads keep Valhalla's urban/rural defaults.
    基準＝OpenStreetMap の制限速度。無ければ道路交通センサスの「道の種類×人口集中地区の中／外」の制限速度の平均。生活道路などは Valhalla の都市部／郊外の決まった速さ。
  - Factor: per prefecture, motorway or other road, inside or outside a densely inhabited district (DID) — the length-weighted ratio "congested-hour travel speed / speed limit" in the 2021 road traffic census (sections under 30 km use the national value; capped at 1.0). Motorway factors are further multiplied by 0.9.
    係数＝都道府県×高速か一般道か×人口集中地区の中か外か。道路交通センサス（令和3年度）の「混雑時の旅行速度÷指定最高速度」を延長で重み付け（延長30km未満は全国の値・上限1.0）。高速はさらに0.9倍。
  - Motorway ramps without a tagged speed: base x 0.85. Speeds are written as `average_speed` in `mappita/graph_mappita.lua` (a modified copy of Valhalla 3.9.1 `lua/graph.lua`).
- Before tiling, each road (way) gets `mp:pref` (prefecture code, from OSM admin_level=4 boundaries) and `mp:did` (1/0) — `mappita/tag_ways.py`, `mappita/prefs_from_osm.py`.
- Factor tables: `mappita/census_tables.json` (generated by `mappita/census_tables.mjs` from the census per-section CSVs).

Sources / 出典:

- 「令和3年度 全国道路・街路交通情勢調査 一般交通量調査 箇所別基本表」（国土交通省）（https://www.mlit.go.jp/road/census/r3/index.html）を加工して作成（公共データ利用規約 第1.0版）
- 「国土数値情報（人口集中地区データ 2020年）」（国土交通省）（https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A16-2020.html）を加工して作成
